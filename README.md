# Blossom & Bouquet 🌸

Welcome to the official repository for **Blossom & Bouquet**, a modern web application designed for a boutique flower shop specializing in custom, handcrafted seasonal bouquets. 

This project is being built out features step-by-step to create a seamless, interactive front-end experience for browsing and ordering floral arrangements.

## 🚀 Features Implemented So Far

- **Interactive Home Page:** A clean, visually appealing landing layout introducing the shop's concept.
- **Centralized Contact Forms:** Structured inquiry forms positioned centrally for effortless customer communication.
- **Dynamic Running Clock:** A live JavaScript-powered clock component integrated directly into the interface.
- **Secure Authentication System:** Login and signup pages featuring robust client-side form validation and custom error alerts.
- **Show-Password Toggle:** Interactive password visibility eye-icon to improve user experience on credential inputs.

## 🛠️ Tech Stack Used

- **HTML5:** Semantic structure for layouts, navigation, and input forms.
- **CSS3:** Custom styling focusing on layouts, flexbox centering, typography, and interactive hover effects.
- **JavaScript (Vanilla JS):** Core logic handles structural object properties, DOM manipulation, timers, and security rules.

## 📂 Project Structure

```text
├── index.html          # Main Home page of the flower shop
├── login.html          # User Authentication / Sign In page
├── signup.html         # Account Registration / Sign Up page
├── styles.css          # External stylesheet containing layout & presentation rules
└── script.js           # Client-side JavaScript handling dynamic features & validation
```

## ⚙️ How to Run the Project Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the Project Folder:**
   ```bash
   cd blossom-and-bouquet
   ```
3. **Open the Application:**
   Simply double-click the `index.html` file to launch it directly in your preferred web browser, or use a VS Code extension like *Live Server*.
